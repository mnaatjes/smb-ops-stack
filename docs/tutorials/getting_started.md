# Getting Started with smb-ops

This tutorial walks through spinning up `smb-ops` in local development.

## Steps

1. Copy `.env.example` to `.env`.
2. Inspect `SERVICE_HTTP_PORT` (defaults to `8080`).
3. Launch with `docker compose up -d`.
4. Validate service health at `http://localhost:8080`.
