# Architecture Plane: smb-ops

This directory houses the Unified Process (UP) architecture and decision baselines for `smb-ops`.

## Directory Taxonomy

* `adr/`: Architectural Decision Records (MADR 3.0) capturing immutable architectural choices.
* `designs/`: Software Design Documents (IEEE 1016) detailing technical blueprints and schemas.
* `use-cases/`: RUP Functional Use Case specifications.
* `risk/`: Master Project Risk Register (Boehm $RE = P \times I$).
